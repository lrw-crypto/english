# 英文刷題站(四技二專 共同科目 英文 模擬考題庫)

涵蓋 110–114 學年度 25 份模擬考的**選擇題**(共 1048 題),附逐步解析、中譯、單字;
功能:自由練習(依單元/題型/年度篩選)、模擬考、錯題本、錯題 PDF 練習卷、帳號(代稱+4 位數密碼)。

- 網址:https://lrw-crypto.github.io/english/
- 啟用:GitHub → Settings → Pages → Branch `main`、資料夾 `/ (root)`
- 雲端同步(選用):在 `config.js` 填入 Apps Script 網址 `CLOUD_URL`;留空則紀錄只存在該瀏覽器。

> 題目內容為模擬考試題改編/整理,版權屬原出版單位;本倉庫僅供教學使用。
